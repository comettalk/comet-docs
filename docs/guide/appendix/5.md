# 이미지 미리보기 서비스
코멧에서는 외부 이미지를 편리하게 열람할 수 있는 서비스를 제공합니다.

## 서비스 미리보기

위와 같이 많은 이미지를 두 단계에 걸쳐 분류하여 렌더링하고, 이를 공유할 수 있습니다.

## 파라미터 설정
기본값은 **캐릭터 코드**와 **이미지 코드**로 구분됩니다.
직접 텍스트를 클릭하거나 우측의 연필 아이콘을 눌러 편집할 수 있습니다.

## 파라미터 추가
URL 자리에 입력하고 싶은 데이터를 추가할 수 있습니다.
원하는 값을 입력 후 엔터를 누르면 추가됩니다. 이때 양 끝 공백은 제거 후 추가됩니다.

## 파라미터 특수 문법
`[시작 값-끝 값]` 꼴의 특수 문법을 지원합니다.
두 값이 모두 알파벳 대문자, 알파벳 소문자, 정수 중 하나로 동일하다면, 시작과 끝 사이의 모든 값을 순회합니다.

:::info 추가 설명
예를 들어, 파라미터로 [1-3]을 추가했다면 실제로는 `1`, `2`, `3` 모두 순차적으로 추가하게 됩니다.

역순 또한 지원합니다. [C-A]를 추가했다면 `C`, `B`, `A`를 순차적으로 대입합니다.
구간 기호로 `-`뿐만 아니라 `~`, `..`를 사용할 수도 있습니다.
:::

## 이미지 주소 템플릿
미리보기에 사용할 이미지 주소의 형태를 입력합니다.
빨강 / 파랑 색깔로 하이라이팅되는 곳에 파라미터를 순차적으로 대입하게 됩니다.

## 공유
우측의 링크 버튼을 눌러 공유할 수 있습니다.
이때 링크는 **마지막으로 성공적으로 생성한 데이터**를 이용하니, 생성 후 복사를 권장합니다.
