# 프롬프트 압축 키워드
더 적은 글자수로 동일한 뜻을 나타낼 수 있게 해주는 방법을 알아봅시다.

## 한자어 사용
사용 의도가 명확하다면, 한자어를 사용하여 더욱 줄여볼 수 있습니다.
주로 색상, 감정 등의 부분에서 한자어를 사용해볼 수 있습니다.

```markdown
[흰 머리, 파란 눈] -> [백발, 청안]
차갑고 쌀쌀맞음 -> 냉정함
```

## 다국어 프롬프팅
한국어와 영어 이외의 다른 언어를 가져오는 방법입니다.
가장 대표적으로 쓰이는 문자로는 한자가 있습니다.

다만, 프롬프트에서 제3의 언어는 사실상 "특수 문자" 취급입니다.
언어가 뒤섞일 경우 응답 품질이 과하게 내려갈 수 있기 때문에 주의해야 합니다.

:::warning ⚠️ 혼용 금지
"그녀는 冷情한 성격이다." 와 같이 섞어쓰는 행위는 **금기**에 가깝습니다.
전형적인 망가진 텍스트나 암호문에 가까워지기 때문에 응답 품질에 치명적입니다.

중국어 프롬프트를 쓰려고 하는 경우, 특정 세션 안에서만, 다른 언어 없이 쓰여야 합니다.
:::

코멧에서 권장하는 수준은 "성별 표시" 정도만 사용하는 것을 권장합니다.
男, 女 정도는 꽤 많이 쓰이는 글자이기에 토큰 최적화도 되어있고, 의미도 매우 명확합니다.

## MBTI, 에니어그램
캐릭터 성격의 기본 구조를 잡는 방법입니다.
주로 겉으로 드러나는 성격은 **MBTI**, 속마음 관련 성격은 **에니어그램**으로 설계하는 경우가 많습니다.

## 치환?
간혹 아래와 같은 프롬프팅 기법을 확인할 수 있습니다.
```markdown
{user}=U
{char}=C
```

이런 방식으로, `{user}`와 `{char}`를 각각 알파벳으로 치환 후, 이후 단어를 줄임말로 사용하는 기법입니다.
결론부터 말하자면, 코멧에서는 **매우 권장하지 않습니다.**

먼저 코멧은 처음부터 시뮬레이션과 같은, 다양한 방향으로의 캐릭터 채팅에 초점을 두고 설계되었습니다.
코멧 시스템 프롬프트에서는 `{char}`라는 키워드를 **쓰지 않습니다.**

기본적으로 세계관을 받아 스토리텔링을 이어가는 시스템이기에, 
세계관과 캐릭터에만 집중하여 설계하여도 무방합니다.

또한, 치환이라는 개념 자체가 지속적으로 치환 프롬프트를 참고해야 하기 때문에, 어텐션 알고리즘에 악영향을 끼칩니다.
특수문자에 의미를 주입해 사용하는 치환 방식 역시 악영향을 끼치고, 특수문자를 넣는 프롬프팅 방식 자체가 불안정한 면이 크다 보니 권장되지 않는 사항입니다.
