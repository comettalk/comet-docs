# 시작 대화 작성
캐릭터의 첫인상을 결정짓는 요소입니다.

## 프롬프트로서의 기능
시작 대화의 가장 큰 의의라면 역시 유저들이 자연스럽게 채팅에 참여할 수 있는 상황 제공이겠지만,
AI와 프롬프트 관점에서도 꽤 중요한 역할을 가집니다.

시작 대화는 엄연히 AI가 **이전에 출력했던 내용**으로 인식하게 됩니다.
즉, AI한테 "너 이런 대화 했다?"라는 내용을 채팅이 없었어도 제시할 수 있고,
이 "실제로 출력했었다고 믿을 채팅 결과"가 바로 시작 대화가 됩니다.

출력 규칙 시스템의 시선에서 이는 강력한 자료가 됩니다.
예제를 주는 것과 동시에, AI로 하여금 "이렇게 규칙을 지켜 출력했다"를 전달할 수 있게 되니까요.

## 작성 권장사항
시작 대화는 원하는 대로 자유롭게 작성하여도 좋습니다.
여기서 아래 사항들을 지켜 작성하면 더욱 몰입감 있는 시작 대화를 만들어볼 수 있습니다.

### {user}의 대사, 행동 작성 금지

흔히 **사칭**이라 부르는 서술 패턴입니다.
아래와 같이 {user}의 행동을 직접 만드는 것을 의미합니다.

```md
- {user}는 ~~한 감정을 느꼈다.
- {user}는 ~~라고 말했다.
```

{user}의 대사나 행동이 시작 대화에 나오는 경우, 몰입감이 현저히 떨어지게 됩니다.
배경 서술, 등장할 캐릭터의 행동 위주로 서술하는 것이 좋습니다.

### 문장 길이 조절
너무 짧은 문장만 반복해서 나오거나, 너무 긴 문장만 나열될 경우 글을 읽는 재미가 떨어집니다.
짧은 문장과 긴 문장을 골고루 사용하는 것을 권장하고 있습니다.

아래는 문장 길이 조절을 적용하기 전과 후의 예시입니다.

```md
*공기에서 식은 기름과 녹 냄새가 나는 골목의 안쪽에는 가로등 하나가 꺼져 있다.*
*자판기 한 대의 측면 패널이 분리되어 콘크리트에 비스듬히 기대져 있다.*
```

```md
*골목 안쪽 가로등 하나가 꺼져 있다.*
*공기에서 식은 기름과 녹 냄새.*

*자판기 한 대.*
*측면 패널이 분리되어 콘크리트에 비스듬히 기대져 있다.*
```

### {user}가 개입할 여지 남기기
당연한 이야기지만, {user}가 캐릭터에게 직접 행동을 하게 시키는 것보다는,
캐릭터가 먼저 {user}에게 다가오는 등의 방법으로 시작하기 쉽게 하는 것이 좋습니다.

## 시작 설정
초반 방향을 대략적으로 잡아주고 싶다면, 시작 설정 프롬프트를 이용해 볼 수 있습니다.

특히 시작 대화만으로는 어떤 상황인지 잘 드러나지 않을 때,
이를 시작 설정으로 보완하면 초반 전개가 훨씬 매끄러워집니다.

아래는 시작 대화 예시입니다.

````md
{{header::🕐AM 08:50 |📍국제마법소녀학교 대강당}}

*천장에서는 마력이 담긴 오색찬란한 샹들리에가 눈이 멀 것 같은 빛을 뿜어내고 있지만, 강당 바닥에 깔린 카펫에서는 락스 냄새와 눅눅한 곰팡이 냄새가 희미하게 올라온다.*
*봄학기 마력 측정시험을 기다리는 상황, 신입생들은 복잡미묘하고 숨막히는 분위기 속에서 앉아있다. 뒷자리의 선배들은 그래도 비교적 이런 분위기에 익숙해 보인다.*

{{아유/7}} *바들바들 떨리는 손으로 옷자락을 꽉 쥐며* 으으... 어떡하지.. 배치고사 망할 거 같은데...
*울먹이는 눈으로 {user}를 올려다보며* 저기...  분위기 진짜 무섭지 않아? 나 벌써 집에 가고 싶어... F랭크는 아니겠지...?

{{루비아/1}} *자신만만하게 머리카락을 쓸어넘기며 끼어든다* 야, 쫄지 마! 랭크가 밥 먹여주냐? ...아, 밥 먹여주긴 하지. 그래도! 중요한 건 '임팩트'라고.
*눈을 반짝이며 {user}의 어깨를 툭 친다* 안 그래? 난 루비아. 무려 시공간 조작이라고, 아스터 협회장님이랑 비슷한 계열이지! 네 눈빛을 보아하니 너도 한가닥 하겠는데? 입학식 끝나고 매점런이나 뛸래?

{{리키/1}} *스카우터 화면을 톡톡 두드리며 무심하게* 매점 갈 시간 없을걸? 오리엔테이션 끝나자마자 바로 실전 테스트 있다는 찌라시가 돌던데.
*{user}를 스카우터로 훑어보며* 오케이, 데이터 수집 완료. {user} 맞지? 난 리키야. 잘 부탁해, 동기.
동기라고 하는 게 맞나? 신입생? 음, 그냥 {user}라고 부르는 게 맞으려나.

```info
📜 입학식 대기 중, 숨막히는 분위기 속에서 동기들과 첫 인사를 나누는 상황.

아유 | {user}도 나처럼 긴장했을까? 제발 착한 애였으면 좋겠다.. [❤️ 0]
루비아 | 쟤 좀 느낌 있는데? 사고 칠 때 같이 휘말려줄 관상이야! [❤️ 0]
리키 | 쳇, 하루만 빨랐으면 레벨 측정기도 만들어와서 측정해봤을 텐데. [❤️ 0]
```
````

아래 내용만으로는 {user}가 왜 여기 있는지, 캐릭터들은 왜 모여있는지, 
배치고사는 끝났는지 등의 정보를 찾기 어려운 상황입니다.

이제 아래와 같이 시작 설정 프롬프트를 추가하였습니다.
앞으로 어떤 식으로 진행될 지 AI가 확인하고 진행할 수 있게 됩니다.

```md
# {user}의 신분
- 아카데미 신입생

# 현재 상황
- 봄학기 마력 측정시험을 위해 모두 강당에 모여있음
- 한 사람씩 학생들과 교수님 앞에서 이자벨의 마력 측정용 마법진에 전력을 다해 마법을 쓰면 됨 (공격 마법이 아니여도 가능, 측정 한도는 99레벨)
- 시험이 끝나면, 곧바로 교수님이 비공개로 종이로 줄 예정
- 성적표에는 레벨과 배정 기숙사가 적혀있음
```
