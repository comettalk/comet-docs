# 이미지
이미지는 캐릭터에서 가장 중요한 시각적 요소입니다.
구체적으로 이미지를 뽑는 방법보단, 이미지를 사용하는 원리를 이해합니다.

## 이미지 생성 사이트
가장 대표적으로 쓰이는 두 가지 사이트입니다.
만약 이미 쓰고 있는 이미지 생성 ai 사이트가 있다면 유지하셔도 좋습니다.

### [NovelAI](https://novelai.net)
유료 이미지 생성 사이트 중에서는 가장 널리 알려진 사이트입니다.
최근에는 30회를 무료로 생성해볼 수 있으므로 간단히 테스트해보시는 것을 추천드립니다.

### [PixAI](https://pixai.art/)
매일 무료로 소량의 이미지를 생성해볼 수 있는 사이트입니다.
일일 재화가 있어 평소에 꾸준히 재화를 적립해놓으면 무료로 이미지를 생성하는 것이 가능합니다.


## 파일 확장자와 WebP
코멧의 경우 내부 이미지 업로드의 용량 제한은 5MB로 제한되어 있습니다.
또한, 일반적으로 이미지 용량이 클 경우 로딩 속도가 느려진다는 단점이 있습니다.

일반적으로 이미지를 저장할 경우 사용하는 확장자인 `.jpg`, `.png` 등은 효율이 그닥 좋지 않기 때문에,
가급적이면 `.webp` 확장자로 변환하여 사용하는 것을 추천드립니다.

WebP 변환 프로그램의 경우 `png to webp` 등의 키워드를 통해 나오는 사이트를 활용해도 되고,
[ImageMagick](https://imagemagick.org/)같은 전문 툴을 사용하는 것도 가능합니다.


## AI에게 이미지는 텍스트일 뿐
AI는 이미지를 파악하고 어떤 이미지인지 알지 못합니다.
이미지가 사용되는 원리는 특정 텍스트에 이미지라는 이름을 붙이고, 이미지 설명을 더해주어 AI에게 "이 텍스트는 이런 이미지야" 라고 이해시키는 것입니다.

구체적으로는 렌더링의 일종이며, 이는 이후 매크로 문서에서 간략하게 짚고 넘어갑니다.
