# 로어북
선택적으로 불러오는 프롬프트를 작성합니다.

![](https://image.comet-talk.ai/guide/tutorial/cinema/tab5.png)

## 로어북 생성
로어북 추가 버튼을 눌러 생성할 수 있습니다.
노벨챗은 최대 **100**개까지, 프로챗은 최대 **1000**개까지 생성 가능합니다.

## 우선순위 변경
좌측 핸들을 드래그하여 위치를 변경할 수 있습니다.
동시에 여러 로어북을 불러올 경우, 위쪽 로어북부터 순차대로 사용합니다.

## 로어북 편집
우측의 연필 모양 아이콘을 클릭해 편집합니다.
![](https://image.comet-talk.ai/guide/tutorial/cinema/lorebook-modal.png)

### 로어북 제목
어떤 로어북인지 메모합니다. 프롬프트에는 적용되지 않습니다.

### 내용
추가적으로 불러올 프롬프트를 작성합니다.

노벨챗은 최대 **500**자까지 입력 가능하며, 공백은 글자수 집계에서 제외됩니다.
프로챗은 최대 **5000**자까지 입력 가능합니다.

### 키워드
로어북이 발동될 단어를 지정합니다. 키워드 입력 후 **Enter** 키를 누르면 키워드가 등록됩니다.
각 키워드별로 최대 **10**자까지, 최대 **10**개의 키워드를 등록할 수 있습니다.

유저의 채팅이나 AI의 직전 채팅에 키워드가 포함된다면, 로어북의 내용을 불러옵니다.
