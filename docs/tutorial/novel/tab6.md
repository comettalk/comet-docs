# 업로드
캐릭터 제작을 마무리합니다.

![](https://image.comet-talk.ai/guide/tutorial/novel/tab6.png)

## 공개 여부
캐릭터 공개 여부를 설정합니다.

| 설정값 | 설명 |
| :-: | :- |
| **공개** | 모두가 플레이할 수 있습니다. |
| **링크 공개** | 메인에 노출되지 않습니다. 링크를 통해 접속해야만 플레이 가능합니다. |
| **비공개** | 제작자 자신만 플레이 가능합니다. |

## 태그
해시태그를 설정할 수 있습니다.
각 키워드별로 최대 **10**자까지, 최대 **10**개의 키워드를 등록할 수 있습니다.
