# 업로드
캐릭터 제작을 마무리합니다.

![](https://image.comet-talk.ai/images/1787491823112-ce014033-2364-47b4-b546-92138e7e4a6e)

## 공개 여부
캐릭터 공개 여부를 설정합니다.

| 설정값 | 설명 |
| :-: | :- |
| **공개** | 모두가 플레이할 수 있습니다. |
| **링크 공개** | 메인에 노출되지 않습니다. 링크를 통해 접속해야만 플레이 가능합니다. |
| **비공개** | 제작자 자신만 플레이 가능합니다. |

## 캐릭터 정보 제공
캐릭터 프롬프트를 학습에 사용하는 모델의 사용 가능 여부를 설정합니다.

## 기본 모델
사용자가 캐릭터 플레이 시 기본적으로 선택될 모델을 설정합니다.

## 연관 키워드
해시태그를 설정할 수 있습니다.
각 키워드별로 최대 **10**자까지, 최대 **10**개의 키워드를 등록할 수 있습니다.

## 플레이 가이드
플레이 도중 "가이드"를 눌러 언제든지 확인해볼 수 있는 메모를 작성합니다.
최대 **2000**자까지 작성 가능합니다.
