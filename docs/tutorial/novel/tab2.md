## 로어북 적용 한도
동시에 적용되는 로어북의 **최대 개수**를 설정합니다.

설정 시 메인 프롬프트의 글자 수 제한이 변경됩니다.
이미 작성된 메인 프롬프트의 글자 수에 따라 개수 선택지가 변경되며, 최대 개수는 **10**개입니다.

## 프롬프트
캐릭터의 성격, 특징, 세계관, 규칙 등 롤플레잉에 필요한 정보를 서술합니다.

기본 모드는 최대 `12500 - (로어북 개수) x 500`자까지 입력 가능하며, 공백은 글자수 집계에서 제외됩니다.
제한 초과 시 프로 전용으로 활성화됩니다. 글자수가 노랗게 표시되고, 제한이 넓어집니다.
