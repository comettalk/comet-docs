# 시작 세션
캐릭터의 첫 대화와 시작 상황을 설정합니다.

![](https://image.comet-talk.ai/guide/tutorial/novel/tab3.png)

## 생성 및 삭제
상단의 **+** 기호를 눌러 새 세션을 생성합니다.
시작 세션 이름 옆의 **x** 기호를 눌러 세션을 삭제합니다.

최소 **1**개, 최대 **5**개까지 설정 가능합니다.

## 세션 이름
플레이 시 유저들에게 보여질 제목입니다. 최대 **15**자까지 입력 가능합니다.

## 시작 상황
세션의 시작 상황을 요약적으로 작성합니다.

노벨챗은 최대 **1000**자까지 입력 가능하고, 공백은 글자수 집계에서 제외됩니다.
프로챗은 최대 **10000**자까지 입력 가능합니다.

## 시작 대화
유저에게 처음으로 보여줄 대화입니다.

노벨챗은 최대 **1000**자까지 입력 가능합니다.
프로챗은 최대 **10000**자까지 입력 가능합니다.
