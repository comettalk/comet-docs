# 매크로
정규식을 활용하여 오류를 보정하고, 다양한 연출을 생성합니다.

![](https://image.comet-talk.ai/images/1787491130435-a0f1465a-bd3d-4244-ac22-2571b9bd6980)

## 매크로 생성
매크로 추가 버튼을 눌러 생성할 수 있습니다. 최대 **1000**개까지 생성 가능합니다.

**이미지 아이콘**을 통해 이미지를 업로드할 수 있습니다.
각 파일별로 최대 **5MB**까지만 업로드 가능하며, 자동으로 마크다운 이미지로 변환되는 매크로를 생성합니다.

**대괄호 아이콘**을 클릭해 매크로 JSON 파일을 업로드할 수 있습니다.
조건 만족 시 대체 여부를 확인하며, 확인할 경우 매크로 리스트를 파일 데이터로 대체합니다.

자세한 포맷은 [추가 자료](../../guide/appendix/5.md)를 통해 확인 가능합니다.

## 우선순위 변경
좌측 핸들을 드래그하여 위치를 변경할 수 있습니다.
매크로는 위쪽 매크로부터 순차적으로 적용됩니다.

## 매크로 편집
우측의 연필 모양 아이콘을 클릭해 편집합니다.
![](https://image.comet-talk.ai/images/1787491260507-9840aefa-0da8-4ad9-a992-35e66db037de)

## 일대일 치환

### 타겟 키워드
감지할 문자열을 입력합니다.

### 대체 키워드
대체할 문자열을 입력합니다.

설정 완료 시 모든 `(타겟 키워드)`가 `(대체 키워드)`로 변경되어 보여집니다.


## 정규식 치환

### 정규식
감지할 정규식을 입력합니다.

### 대체식
대체할 식을 입력합니다.

설정 완료 시 모든 감지된 `(정규식 패턴)` 문자열이 `(대체식)`으로 변경되어 보여집니다.


## 정규식 체인

### 정규식
감지할 정규식을 입력합니다.

### 접두사, 접미사
앞, 뒤에 붙여질 문자열을 입력합니다.

설정 완료 시 모든 감지된 `(정규식 패턴)` 문자열에 대해 다음 정규식이 전체 문자열 대신 처리합니다.

캡처 그룹이 존재하지 않을 경우 매칭된 전체 문자열이 다음 정규식으로 전달됩니다.
캡처 그룹이 존재할 경우 첫 번째 캡처 그룹이 다음 정규식으로 전달됩니다.

처리 결과에 대해, `(접두사)(처리 결과)(접미사)`로 변경되어 보여집니다.
