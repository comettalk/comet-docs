# 제작 종류
코멧은 다양한 창작 생태계를 위해 여러 유형의 제작 환경을 제공합니다.

## 시네마챗
![](https://image.comet-talk.ai/guide/chat-type/cinema-preview.png)

16:9 형태의 고정 비율 화면으로, 게임같은 몰입감을 주는 채팅을 제작합니다.
터치로 대사를 넘기고, 상태창을 열람하는 등의 기능을 제작할 수 있습니다.


## 노벨챗

![](https://image.comet-talk.ai/guide/chat-type/novel-preview.png)

이미지가 포함된 텍스트 형식으로 진행되는 가장 일반적인 형태의 채팅을 제작합니다.
HTML과 정규식을 지원하여 더욱 다양한 연출을 제작하실 수 있습니다.


## 템플릿

![](https://image.comet-talk.ai/guide/chat-type/template-preview.png)

시네마챗에 사용되는 UI를 제작합니다.
변수 설정, 스크립트 등의 전문적 환경을 제공합니다.
