# 에디터
오브젝트의 설정들을 구성합니다.

![](https://image.comet-talk.ai/guide/tutorial/template/tab3.webp)

## 캔버스 정보
**1280 x 720**의 좌표계로 구성됩니다.
왼쪽 위 꼭짓점의 좌표가 (0, 0)이고, 오른쪽 아래 꼭짓점의 좌표가 (1280, 720)입니다.

선택된 오브젝트는 테두리가 표시되며, 드래그를 통해 이동이나 크기 조절이 가능합니다.

미리보기의 오른쪽 위 아이콘을 눌러 전체보기로 볼 수 있습니다.

스크립트 실행 버튼을 눌러 스크립트가 동작하는 상태를 확인할 수 있습니다.

## 오브젝트 종류
**텍스트**: 설정된 공간에 텍스트를 표시합니다.

**이미지**: 고정된 이미지 파일을 표시합니다. 클릭 시 이벤트를 설정할 수 있습니다.

**프레임**: 바뀌는 이미지를 표시합니다.
시네마챗에서 등록된 이미지를 사용하는 것을 권장하지만, 이미지 원본 주소도 로드 가능합니다.

## 공통 성분

### x, y
오브젝트의 왼쪽 위 꼭짓점의 **x, y 좌표**입니다. 숫자만 입력 가능합니다.

### width, height
오브젝트의 **가로 길이**, **세로 길이**입니다. 숫자만 입력 가능합니다.

### state
상태 스크립트를 설정합니다.

## 텍스트 오브젝트 성분

### value
표시될 **값**을 스크립트로 설정합니다.

### fontSize(px)
**텍스트의 크기**를 지정합니다. 숫자만 입력 가능합니다.

### color(code)
텍스트의 **색상**을 설정합니다. 헥스코드가 일반적입니다.
black, white 등의 일반적인 색상 키워드도 사용 가능합니다.

### textAlign
텍스트 **정렬** 방법을 설정합니다.
| **left** | **center** | **right** |
| :-: | :-: | :-: |
| 좌측 정렬 | 중앙 정렬 | 우측 정렬 |

### easing
텍스트 **등장 효과**를 설정합니다. 넘기기에 영향을 받은 경우에만 나타납니다.
| **none** | 값이 변하면 즉시 변합니다. |
| :-: | :-: |
| **typing** | 텍스트가 한 글자씩 출력됩니다. |
| **fade** | 투명 상태에서 불투명 상태로 나타납니다. |

### overflow
텍스트가 넘칠 경우, **스크롤 여부**를 설정합니다.

| **hidden** | 스크롤이 비활성화됩니다. |
| :-: | :-: |
| **scroll** | 스크롤이 활성화됩니다. |

### white-space
**줄바꿈 여부**를 결정합니다.

| **normal** | 텍스트가 가로로 길어질 경우에만 줄을 바꿉니다. (엔터 키 비활성화) |
| :-: | :-: |
| **pre-wrap** | 엔터 키를 통한 줄바꿈이 활성화됩니다. |

### font
**글꼴**을 설정합니다.

### font weight
**글꼴 두께**를 설정합니다.
:::warning ⚠️ 안내사항
글꼴별로 지원하는 두께가 다릅니다. 직접 테스트를 통해 설정하시는 것을 추천합니다.
:::

## 이미지 오브젝트 성분

### action
**클릭** 시 실행할 스크립트를 설정합니다.

## 프레임 오브젝트 성분

### value
표시될 **값**을 스크립트로 설정합니다.
설정값과 같은 이름을 가진 이미지가 있다면 해당 이미지를 사용하고, 그렇지 않다면 설정값을 이미지 원본 주소로 사용합니다.

### borderRadius
가장자리를 부드럽게 깎는 정도를 설정합니다. 수만 입력 가능합니다.

### object-fit
이미지 비율이 맞지 않을 경우 **렌더링 방식**을 설정합니다.

| **contain** | 공백을 추가하여 크기를 맞춥니다. |
| :-: | :-: |
| **cover** | 넘치는 부분을 잘라내어 크기를 맞춥니다. |

### moping
이미지 **전환 방식**을 설정합니다.

| **none** | 즉시 이미지를 변경합니다. |
| :-: | :-: |
| **fade** | 기존 이미지가 서서히 사라지고, 이후 새로운 이미지가 서서히 등장합니다. |
| **cross-fade** | 기존 이미지가 서서히 사라지며 동시에 새로운 이미지가 서서히 등장합니다. |

### duration(ms)
**등장 속도**를 설정합니다. moping 설정이 **fade**, **cross-fade**일 경우에만 사용됩니다.
