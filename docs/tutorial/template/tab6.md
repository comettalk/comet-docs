# 트리거
이벤트 감지 시 실행할 스크립트를 설정합니다.

![](https://image.comet-talk.ai/guide/tutorial/template/tab6.png)

## 트리거 편집
**좌측 아이콘** 버튼을 눌러 트리거 유형을 설정할 수 있습니다.
현재 아래와 같은 이벤트가 지원됩니다.

| **템플릿 로드 완료** | 템플릿이 처음 로드되었을 때 최초 1회 실행합니다. |
| :-: | :- |
| **키 입력** | 특정 키가 눌렸을 때 실행합니다.<br>버튼 우측의 박스를 누르고 원하는 키를 눌러 키 설정이 가능합니다. |

## 트리거 실행 순서
같은 이벤트를 가진 트리거가 동시에 발동될 경우, 위쪽 트리거부터 순서대로 발동합니다.
트리거의 삼각형 아이콘을 클릭해 트리거 발동 순서를 변경할 수 있습니다.

## 스크립트 편집
트리거의 연필 아이콘을 클릭해 스크립트를 편집할 수 있습니다.
스크립트 타입은 **action** 스크립트를 사용합니다.

## 스크립트 삭제
트리거의 X 아이콘을 눌러 삭제할 수 있습니다.
