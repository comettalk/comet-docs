# 프롬프트
템플릿의 시스템을 설계합니다.

![](https://image.comet-talk.ai/guide/tutorial/template/tab2.webp)

## 프롬프트
어떤 변수에 어떻게 대입할 지 프롬프트를 통해 명령하는 부분입니다.
최대 **1000**자까지 작성 가능합니다.

## 변수
AI가 사용할 수 있는 공간을 생성합니다.
모든 변수의 이름은 서로 달라야 합니다.

**전역 변수**는 AI가 사용하는 변수이고, 최대 **20**개까지 생성 가능합니다.
**시스템 변수**는 후술할 스크립트에서 사용하는 변수로, 최대 **200**개까지 생성 가능합니다.

:::details 변수 시스템 설명
시네마챗에서는 응답을 여러 개로 나눕니다.
**어떤 변수**를 **어떤 데이터**로 변경할 지 여러 차례에 걸쳐 순서대로 출력합니다.
(지정 변수와 변경 데이터를 묶어서 로그라고 부릅니다.)

변수를 활용하면 일반적인 채팅에선 불가능한, 더욱 복잡한 시스템도 구현할 수 있습니다.
:::

## 변수 설정
전역 변수의 경우 v 버튼을 눌러 수정할 수 있습니다.

![](https://image.comet-talk.ai/guide/tutorial/template/edit-var.png)

### 변수명
최대 **10**글자까지 입력 가능합니다. 중복은 허용되지 않습니다.

### 자동 넘기기
해당 변수가 로그로 변경되면, 자동으로 다음 로그도 실행할 지 설정합니다.

:::details 추가 설명
아래 로그를 가정합니다.
```
로그 1 | 변수명: "대사", 데이터: "안녕!"
로그 2 | 변수명: "이미지", 데이터: "1"
로그 3 | 변수명: "대사", 데이터: "반가워!"
```

이때 이미지 변수의 자동 넘기기가 활성화되어있다면,
로그 1이 실행된 상태에서 넘겼을 경우 이미지가 "1"로, 대사가 "반가워!"로 **동시에** 변경됩니다.
:::

### 타입
변수에 들어갈 데이터의 종류를 제한합니다.
AI한테만 적용되는 설정으로, 제작자나 플레이어에게는 적용되지 않습니다.

:::details 설정 목록
**문자열**
가장 일반적인 형식입니다. 단어나 문장을 자유롭게 입력합니다.

**정수**
1, 2, 3처럼 소수점이 없는 수만 사용 가능합니다.

**실수**
수만 사용 가능합니다.

**참/거짓**
`true`, `false`만 사용 가능합니다.
