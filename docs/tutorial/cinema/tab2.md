# 프롬프트
캐릭터의 성격, 특징, 세계관, 규칙 등 롤플레잉에 필요한 정보를 서술합니다.

![](https://image.comet-talk.ai/images/1787492164284-02e2cbd4-e84a-48b8-8974-6cfcc2e5b7ec)

## 템플릿
캐릭터에 사용할 템플릿을 설정합니다.
캐릭터 수정의 경우, **변경 안함**을 선택할 경우 템플릿을 변경하지 않습니다.

## 로어북 예산
동시에 적용되는 로어북의 **최대 글자수**를 설정합니다.

설정 시 메인 프롬프트의 글자 수 제한이 변경됩니다.
0자부터 최대 **5000**자까지, 250자 단위로 설정이 가능합니다.

## 프롬프트
캐릭터의 성격, 특징, 세계관, 규칙 등 롤플레잉에 필요한 정보를 서술합니다.
기본 모드는 최대 `7500 - (로어북 예산)`자까지 입력 가능하며, 공백은 글자수 집계에서 제외됩니다.
제한 초과 시 프로 전용으로 활성화됩니다. 글자수가 노랗게 표시되고, 제한이 **75000자**로 넓어집니다.
