# 업로드
캐릭터 제작을 마무리합니다.

![](https://image.comet-talk.ai/images/1787492414484-a93e7d5a-0eed-4715-a95d-927c0bf61716)

## 공개 여부
캐릭터 공개 여부를 설정합니다.

| 설정값 | 설명 |
| :-: | :- |
| **공개** | 모두가 플레이할 수 있습니다. |
| **링크 공개** | 메인에 노출되지 않습니다. 링크를 통해 접속해야만 플레이 가능합니다. |
| **비공개** | 제작자 자신만 플레이 가능합니다. |

## 기본 모델
사용자가 캐릭터 플레이 시 기본적으로 선택될 모델을 설정합니다.

## 연관 키워드
해시태그를 설정할 수 있습니다.
각 키워드별로 최대 **10**자까지, 최대 **10**개의 키워드를 등록할 수 있습니다.
