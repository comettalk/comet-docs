# 시작 세션
캐릭터의 첫 대화와 시작 상황을 설정합니다.

![](https://image.comet-talk.ai/images/1787492252743-e07d9914-d13b-4c18-bddb-13013293e2f3)

## 생성 및 삭제
상단의 **+** 기호를 눌러 새 세션을 생성합니다.
시작 세션 이름 옆의 **x** 기호를 눌러 세션을 삭제합니다.

최소 **1**개, 최대 **10**개까지 설정 가능합니다.

## 세션 이름
플레이 시 유저들에게 보여질 제목입니다. 최대 **15**자까지 입력 가능합니다.

## 기본값
변수의 초기 값을 설정합니다.
기본 모드의 경우 초기 값의 글자수 총합은 최대 **250**자 이내여야 합니다.
프로 모드의 경우 초기 값의 글자수 총합은 최대 **250**자 이내여야 합니다.

## 시작 상황
세션의 시작 상황을 요약적으로 작성합니다.
기본 모드는 최대 **1000**자까지 입력 가능하고, 공백은 글자수 집계에서 제외됩니다.
프로 모드는 최대 **10000**자까지 입력 가능하고, 공백은 글자수 집계에서 제외됩니다.

## 인트로
유저에게 처음으로 보여줄 대화입니다.
기본 모드는 최대 **40**개까지 생성 가능하며, 글자수 총합은 최대 **1000**자 이내여야 합니다.
프로 모드는 최대 **400**개까지 생성 가능하며, 글자수 총합은 최대 **10000**자 이내여야 합니다.

| 단축키 | 설명 |
| :-: | :- |
| **Ctrl + Enter** | 즉시 편집 중이던 로그의 바로 밑에 새 로그를 생성합니다. |
| **Backspace** | 내용이 없을 경우 로그를 삭제합니다. |
| **위, 아래 키** | 로그의 커서 위치를 이동합니다. |
