# 이미지
캐릭터에 사용되는 이미지를 등록합니다.

![](https://image.comet-talk.ai/guide/tutorial/cinema/tab4.png)

## 업로드
우측 상단의 **이미지 업로드** 버튼을 눌러 등록할 수 있습니다.
기본 모드는 최대 **100**개까지 업로드 가능하며, 이미지당 최대 용량은 **5MB**입니다.
프로 모드는 최대 **100**개까지 업로드 가능합니다.

## 이미지 정보 설정
![](https://image.comet-talk.ai/guide/tutorial/cinema/image-modal.png)

### 이미지 변경
좌측 이미지를 클릭하여 이미지를 재업로드할 수 있습니다.

### 이미지 이름
변수 할당에 사용되는 이미지 명칭입니다. 최대 **15**자까지 설정 가능하며, 중복되지 않아야 합니다.

### 이미지 설명
이미지를 간략히 설명합니다. 최대 **30**자까지 입력 가능합니다.
