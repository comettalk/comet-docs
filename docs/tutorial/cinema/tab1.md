# 기본 정보
유저들에게 공개적으로 공유되는 부분입니다.

![](https://image.comet-talk.ai/guide/tutorial/cinema/tab1.png)

## 썸네일
**16:9** 비율의 이미지를 업로드합니다.
5MB 이하의 이미지만 사용 가능합니다.

## 템플릿 공개
다른 유저도 템플릿을 쓰게 할 지 설정합니다.
공개 시 다른 유저도 해당 템플릿을 사용할 수 있습니다.

## 제목
캐릭터의 제목입니다. 최대 **20**자까지 설정 가능합니다.

## 설명
캐릭터에 대한 소개를 작성합니다. 최대 **2500**자까지 설정 가능합니다.
