# 로어북
선택적으로 불러오는 프롬프트를 작성합니다.

![](https://image.comet-talk.ai/images/1787491313437-92a3f44c-22b8-47ee-be63-9869504a5d2e)

## 로어북 생성
로어북 추가 버튼을 눌러 생성할 수 있습니다.
최대 **500**개까지 생성 가능합니다.

**대괄호 아이콘**을 클릭해 로어북 JSON 파일을 업로드할 수 있습니다.
조건 만족 시 대체 여부를 확인하며, 확인할 경우 로어북 리스트를 파일 데이터로 대체합니다.

자세한 포맷은 [추가 자료](../../guide/appendix/5.md)를 통해 확인 가능합니다.

## 우선순위 변경
좌측 핸들을 드래그하여 위치를 변경할 수 있습니다.
동시에 여러 로어북을 불러올 경우, 위쪽 로어북부터 순차대로 사용합니다.

## 로어북 편집
우측의 연필 모양 아이콘을 클릭해 편집합니다.
![](https://image.comet-talk.ai/images/1787491400000-962b17c0-6bef-4739-9349-ebb61d8f0099)

### 로어북 제목
어떤 로어북인지 메모합니다. 프롬프트에는 적용되지 않습니다.

### 내용
추가적으로 불러올 프롬프트를 작성합니다.

기본 모드는 최대 `로어북 예산`만큼 입력 가능하며, 공백은 글자수 집계에서 제외됩니다.
프로 모드는 최대 **7500**자까지 입력 가능합니다.

### 트리거
로어북이 발동, 또는 차단될 조건을 지정합니다.
최대 **30**개의 트리거를 등록할 수 있습니다.

각 트리거 필드에 대한 설명은 아래와 같습니다.

### 트리거 유형
`발동`: 트리거가 조건을 만족할 경우 로어북을 활성화합니다.
`통과`: 트리거가 조건을 만족하지 못했을 경우 로어북을 차단합니다.
`차단`: 트리거가 조건을 만족할 경우 로어북을 차단합니다.

### 조건 유형
`키워드`: 텍스트에 지정된 키워드가 포함되었는지 나타냅니다.
`정규식`: 텍스트가 주어진 정규식을 만족하는지 나타냅니다.
`턴수`: 현재 턴수가 주어진 조건을 만족하는지 나타냅니다.
`주사위`: 지정된 주사위의 무작위 선별 결과가 조건을 만족하는지 나타냅니다.

이외의 구체적 필드는 [추가 자료](../../guide/part4/3.md)를 통해 확인할 수 있습니다.

트리거가 조건을 만족했다면, 로어북의 내용을 불러옵니다.
