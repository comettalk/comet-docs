# 페르소나

자신의 캐릭터를 만들고 채팅에서 사용합니다.

## 기본 페르소나 생성

![](https://image.comet-talk.ai/guide/chat-persona/persona-page-preview.png)

[페르소나 페이지](https://comet-talk.ai/persona)에서 자주 쓰는 페르소나를 미리 저장해둘 수 있습니다.
최대 **20**개까지 저장 가능하고, 이름은 최대 **15**자, 설명은 최대 **500**자까지 작성 가능합니다.

클릭하면 **대표 페르소나**로 설정할 수 있고, 흰색 테두리로 표시됩니다.

## 세션에서 사용

우측 상단의 **☰ 버튼** -> **페르소나 설정**을 통해 세션 내 페르소나를 설정할 수 있습니다.

![](https://image.comet-talk.ai/guide/chat-persona/session-persona-modal.png)

세션 생성 시, **대표 페르소나**의 **복사본**이 세션에 저장됩니다.
세션에서 페르소나를 수정해도 기본 페르소나는 영향받지 않습니다.

우측 상단의 불러오기 버튼을 통해 기본 페르소나 중 하나를 복사해올 수 있습니다.
