# 세션 기능
더욱 자유로운 게임플레이를 위한 기능들을 설명합니다.

## 전체 화면
![](https://image.comet-talk.ai/guide/chat-basic/fullscreen.png)

시네마챗 모바일 환경에서 제공됩니다.
화면의 우측 상단 격자 아이콘을 눌러 전체화면으로 플레이 가능합니다.


## 시네마챗 응답 수정
![](https://image.comet-talk.ai/guide/chat-basic/cinema-edit.png)

우측 상단의 **☰ 버튼** -> **응답 수정**으로 수정이 가능합니다.
**+** 버튼을 눌러 현재 확인 중인 로그의 바로 뒤에 새 로그를 생성할 수 있습니다.


## 세션 복사
현재 세션과 동일한 세션을 복사할 수 있습니다.
시네마챗의 경우 우측 상단의 **☰ 버튼** -> **세션 복사**로 복사가 가능합니다.

![](https://image.comet-talk.ai/guide/chat-basic/copy.png)
노벨챗 / 프로챗의 경우 마지막 채팅 하단의 표시된 아이콘을 눌러 복사가 가능합니다.
