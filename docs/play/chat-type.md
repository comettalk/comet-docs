# 채팅 모드

코멧은 다양한 창작 생태계를 위해 여러 유형의 채팅 환경을 제공합니다.
기존 플랫폼에서는 체험해보지 못했던 새로운 채팅 경험을 즐겨보세요.

## 시네마챗

![](https://image.comet-talk.ai/guide/chat-type/cinema-preview.png)

16:9 형태의 고정 비율 화면으로, 게임같은 몰입감을 주는 채팅 환경입니다.
터치로 대사를 넘기고, 상태창을 열람하는 등의 기능을 체험하실 수 있습니다.

## 노벨챗

![](https://image.comet-talk.ai/guide/chat-type/novel-preview.png)

이미지가 포함된 텍스트 형식으로 진행되는 가장 일반적인 형태의 채팅입니다.
HTML과 정규식을 지원하여 더욱 다양한 연출을 체험하실 수 있습니다.

## 프로 모드

![](https://image.comet-talk.ai/guide/chat-type/pro-selector.png)

플레이 시 기본 모드와 프로 모드 중 하나를 선택할 수 있어요.

**기본 모드**는 요약본 기반으로 작동하며, 모델별 플레이 가격이 항상 일정해요.

**프로 모드**는 추론 토큰 및 출력 토큰을 직접 설정할 수 있고, 훨씬 넓은 분량의 프롬프트 양을 지원해요.
가격은 토큰 기반으로 부과되며, 사용량에 비례하여 청구되어요.
