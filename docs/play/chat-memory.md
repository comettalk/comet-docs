# 메모리

스토리 요약, 유저노트, 레퍼런스 등을 설정하는 공간입니다.
우측 상단의 **☰ 버튼** -> **메모리 설정**으로 확인 가능합니다.

## 레퍼런스

![](https://image.comet-talk.ai/guide/chat-memory/reference.png)

시스템 프롬프트에 포함되는 지시사항을 설정합니다.

::: info 사칭 방지
AI가 대신 유저의 대사, 행동을 생성하는 현상을 방지합니다.
기본적으로 활성화 상태입니다.
:::

::: info 신격화 방지
사용자를 절대적인 존재로 인식하는 현상을 방지합니다.
:::

## 요약본

![](https://image.comet-talk.ai/guide/chat-memory/summaries.png)

대화를 여러 개의 구간으로 나누어 각각의 대화들을 압축한 결과입니다.
우측 상단의 버튼을 눌러 활성화 여부를 설정할 수 있습니다.

::: info 요약 적용
프로 모드의 경우 요약본 활성화 여부를 결정할 수 있습니다.

**요약 적용**이 띄워져 있다면, 요약된 정보를 사용합니다.
**요약 미적용**이 띄워져 있다면, 요약하지 않은 전체 채팅을 사용합니다.
:::


## 요약 프롬프트

요약본 생성 시 추가적으로 사용하는 지시사항을 작성할 수 있습니다.
최대 **250자**까지 입력할 수 있습니다.


## 유저노트

![](https://image.comet-talk.ai/guide/chat-memory/usernote.png)

플레이하면서 자유 양식으로 전달하는 프롬프트를 작성합니다.
잊으면 안 되는 중요한 정보들을 작성하면 좋습니다.

기본 모드는 최대 **4000자**, 프로 모드는 최대 **100000자**까지 입력 가능합니다.
