# 메모리

스토리 요약, 유저노트, 레퍼런스 등을 설정하는 공간입니다.
우측 상단의 **☰ 버튼** -> **메모리 설정**으로 확인 가능합니다.

## 레퍼런스

![](https://image.comet-talk.ai/guide/chat-memory/reference.png)

시스템 프롬프트에 포함되는 지시사항을 설정합니다.

::: info 유저 사칭
AI가 대신 유저의 대사, 행동을 생성하는 현상을 의미합니다.
기본적으로 방지 프롬프트가 적용되어 있으며, 활성화 시 유저 사칭 방지 프롬프트가 제거됩니다.
:::

::: info 유저 신격화
유저의 캐릭터가 절대적인 존재로 인식하는 현상을 의미합니다.
기본적으로 방지 프롬프트가 적용되어 있으며, 활성화 시 유저 신격화 방지 프롬프트가 제거됩니다.
:::

::: info 응답 다양화
Gemini 시리즈의 모델에서만 작동합니다.

기본적으로 활성화되어 있으며, 활성화 시 기존 Gemini 모델의 정형화된 문체들을 방지합니다.
:::

## 요약본

::: info 정보
시네마챗, 노벨챗에서만 활성화되는 기능입니다.
:::

![](https://image.comet-talk.ai/guide/chat-memory/summary.png)

현재까지의 스토리를 압축적으로 요약한 결과입니다.
직접적으로 전달되는 데이터이며, 최대 1만자까지 수정 / 편집이 가능합니다.

요약본은 **10턴**마다 갱신됩니다.

## 대화 요약

::: info 정보
프로챗에서만 활성화되는 기능입니다.
:::

![](https://image.comet-talk.ai/guide/chat-memory/summaries.png)

대화를 10턴 단위로 나누어 압축한 결과입니다.
우측 상단의 버튼을 눌러 활성화 여부를 설정할 수 있습니다.

**요약 적용**이 띄워져 있다면, 요약된 정보를 사용합니다.
**요약 미적용**이 띄워져 있다면, 요약하지 않은 전체 채팅을 사용합니다.

## 유저노트

![](https://image.comet-talk.ai/guide/chat-memory/usernote.png)

플레이하면서 자유 양식으로 전달하는 프롬프트를 작성합니다.
잊으면 안 되는 중요한 정보들을 작성하면 좋습니다.

시네마챗 / 노벨챗은 최대 **3000자**까지 입력 가능합니다.
